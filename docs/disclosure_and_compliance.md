# Disclosure & Compliance

The account is a **fictional character with AI-generated visuals**. The mystery is in-story; the fact that he is fictional is never hidden.

1. **Bio** carries the disclosure line from `settings.disclosure.bio_line` (default: "Fictional character. AI-generated visuals."). Keep it there permanently.
2. **AI label.** Meta requires disclosure of photorealistic AI-generated video and applies "AI info" labels to detected AI imagery. Apply Instagram's AI label to every post. The queue will not approve without `--ai-label`. If your publishing path can't set the label, publish that item manually in the app (or add the label in-app immediately after) and check it shows.
3. **No impersonation.** Never use a real person's face, name, likeness, biography or a creator's signature style as reference or prompt. Don't use reference photos of real people at all; references are generated from the character lock.
4. **The girlfriend is fictional too.** No real person's face; no sexualised content.
5. **Brands.** No logos or readable brand marks (QA criterion 10). Don't imply sponsorship. Any future paid partnership must use Instagram's paid-partnership label.
6. **Publishing** uses only Meta's official Content Publishing API or the Instagram app. No scraping, private APIs, CAPTCHA bypass, credential sharing, bots, fake engagement, purchased followers, or automated follow/DM/comment activity.
7. **Comments**: honest answer to sincere "is he real?" questions (see `voice_and_community.md`).
8. **Music** on Reels: only tracks available in Instagram's licensed library, added in-app.
9. **Secrets**: access tokens live in environment variables, never in the repo.
